# CropDoctor (local)
Put your 3 model files (best_model*.pth, best_config*.json, label_encoder*.json) into `model/` (or next to app.py).
- Windows: double-click `start.bat`
- Mac/Linux: `./start.sh`
The browser opens at http://127.0.0.1:5000. First run downloads packages (a few minutes).
Manual: `pip install -r requirements.txt` then `python app.py`.
